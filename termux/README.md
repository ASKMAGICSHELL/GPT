# Termux

This directory contains tools and scripts intended to run in the Termux Android terminal environment.

## Supported tools

- **Python 3** — run Python scripts from the Termux command line.

Install Python in Termux with:

```bash
pkg update
pkg install python
```

Check the installed version:

```bash
python --version
```

Run a script, for example:

```bash
python py/pr.py
```
